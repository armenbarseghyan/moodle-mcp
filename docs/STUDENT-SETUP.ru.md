# moodle-mcp — инструкция по подключению для студентов

Подключение Moodle FH JOANNEUM к Claude занимает около 15 минут. После этого можно спрашивать
на любом языке: *«что сдавать на этой неделе?»*, *«где инструкция по лабораторной VM?»*,
*«что преподаватель написал про мою домашку?»*.

> **Только чтение.** Сервер может лишь читать твой Moodle: курсы, материалы, дедлайны,
> оценки, объявления. Сдать, написать, записаться или что-то изменить он не может.

English version: [STUDENT-SETUP.md](STUDENT-SETUP.md).

---

## Что понадобится

| | |
|---|---|
| Claude | **Claude Code** (CLI, десктоп-приложение или расширение IDE) — рекомендуется — или **приложение Claude Desktop** |
| Go | 1.25 или новее, чтобы один раз собрать сервер: [go.dev/dl](https://go.dev/dl/) |
| Moodle | твой аккаунт FH JOANNEUM (у каждого студента **свой** токен) |

Проверь Go: `go version` должна показать `go1.25` или новее.

---

## Шаг 1. Скачать код и собрать

```bash
git clone <ссылка на репозиторий, которую тебе дали> moodle-mcp
cd moodle-mcp
make build            # появится bin/moodle-mcp
```

Нет `make` (например, на Windows) — собери напрямую:

```bash
go build -o bin/moodle-mcp ./cmd/moodle-mcp          # macOS / Linux
go build -o bin\moodle-mcp.exe .\cmd\moodle-mcp      # Windows (PowerShell)
```

Проверка: `bin/moodle-mcp -version` выведет версию.

Запомни **полный путь** к бинарнику, он понадобится дальше. Например,
`/Users/anna/moodle-mcp/bin/moodle-mcp` или `C:\Users\anna\moodle-mcp\bin\moodle-mcp.exe`.

## Шаг 2. Получить токен Moodle

Токен — это ключ, с которым сервер читает Moodle **от твоего имени**. Он должен быть от
сервиса **Moodle mobile web service** (`moodle_mobile_app`). Используй первый способ, который
сработает.

### Способ A. Страница ключей безопасности (проще всего)

1. Открой <https://moodle.fh-joanneum.at> и войди.
2. Нажми на аватар (справа вверху) → **Einstellungen** (*Настройки*).
3. В блоке *Benutzerkonto* (*Учётная запись*) открой **Sicherheitsschlüssel** (*Ключи безопасности*).
4. Найди строку **Moodle mobile web service** и скопируй **Schlüssel** (*ключ*). Это строка
   из 32 символов.

Если строка есть, но ключ не виден или не работает, нажми **Zurücksetzen** (*Сбросить*).
Moodle выдаст новый ключ, а старый перестанет работать.

### Способ B. Строки «Moodle mobile web service» нет

Ключ создаётся при первом входе в официальное приложение Moodle.

1. Установи на телефон приложение **Moodle** (от Moodle Pty Ltd).
2. Укажи сайт `https://moodle.fh-joanneum.at` и войди со своим логином и паролем FH.
3. Обнови в браузере страницу *Sicherheitsschlüssel*: строка появится. Дальше — способ A, пункт 4.

### Способ C. Из терминала

Это тот же официальный адрес, через который входит приложение Moodle. В FH JOANNEUM приложение
входит по логину и паролю FH, поэтому так тоже работает. Пароль вводится **только в твой
собственный терминал**, не сохраняется и не показывается на экране.

macOS / Linux:

```bash
read -r -p "FH username: " U; read -r -s -p "FH password: " P; echo
curl -s https://moodle.fh-joanneum.at/login/token.php \
  --data-urlencode "username=$U" --data-urlencode "password=$P" \
  --data-urlencode "service=moodle_mobile_app"; unset P
```

Windows (PowerShell):

```powershell
$u = Read-Host "FH username"; $p = Read-Host "FH password" -AsSecureString
$plain = [Runtime.InteropServices.Marshal]::PtrToStringAuto([Runtime.InteropServices.Marshal]::SecureStringToBSTR($p))
Invoke-RestMethod -Method Post -Uri https://moodle.fh-joanneum.at/login/token.php `
  -Body @{ username = $u; password = $plain; service = "moodle_mobile_app" }
Remove-Variable plain
```

Ответ выглядит так: `{"token":"0123…cdef","privatetoken":"…"}`. Нужен только **token**.

| Ошибка | Что значит |
|---|---|
| `invalidlogin` | неверный логин или пароль |
| `enablewsdescription` / `servicenotavailable` | мобильный сервис для тебя отключён, обратись в IT FH |

### Храни токен в секрете

- Токен работает как пароль от Moodle. **Никому его не давай**: не публикуй в групповых чатах,
  не вставляй в чат с Claude, не коммить в git.
- moodle-mcp только читает, но сам токен не ограничен чтением.
- Потерял, случайно отправил или хочешь отключить доступ — Moodle → *Sicherheitsschlüssel* →
  **Zurücksetzen**. Старый токен перестанет работать сразу.

## Шаг 3. Подключить к Claude

### Claude Code (рекомендуется)

Подставь два значения и выполни один раз:

```bash
claude mcp add moodle -s user \
  -e MOODLE_URL=https://moodle.fh-joanneum.at \
  -e MOODLE_TOKEN=<твой токен> \
  -- <полный путь>/bin/moodle-mcp
```

На Windows запиши команду в одну строку и укажи путь к `moodle-mcp.exe`.

Проверка: `claude mcp get moodle` должна показать **✔ Connected**. Перезапусти Claude Code.

### Приложение Claude Desktop

Открой *Settings → Developer → Edit Config* (файл `claude_desktop_config.json`) и добавь:

```json
{
  "mcpServers": {
    "moodle": {
      "command": "<полный путь>/bin/moodle-mcp",
      "env": {
        "MOODLE_URL": "https://moodle.fh-joanneum.at",
        "MOODLE_TOKEN": "<твой токен>"
      }
    }
  }
}
```

Перезапусти приложение. Инструменты Moodle появятся в меню инструментов нового чата.

### Дополнительные настройки

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `MOODLE_DOWNLOAD_DIR` | `~/Downloads/moodle` | куда сохраняются скачанные файлы и дашборды |
| `MOODLE_LOG_LEVEL` | `info` | `debug` для поиска проблем (токена в логах нет никогда) |

## Шаг 4. Установить скиллы (Claude Code)

Скиллы учат Claude хорошим сценариям поверх инструментов:
- брифинг по учёбе;
- поиск материала и ответ по нему со страницами;
- чек-лист по заданию;
- оценки с фидбеком;
- визуальный дашборд;
- самодиагностика подключения.

```bash
make install-skills          # ссылки из ./skills/* в ~/.claude/skills
```

Без `make`: скопируй (или сделай ссылки на) все папки из `skills/` в `~/.claude/skills/`.
Перезапусти Claude Code. Скиллы написаны по-английски, но работают на любом языке, на котором
ты пишешь.

## Шаг 5. Дать Claude прочитать силлабусы (раз в семестр)

Попроси: *«составь профили моих курсов по силлабусам»*. Claude прочитает силлабус каждого
курса и сохранит правила (компоненты и веса, что нужно сдать отдельно, политику ИИ,
посещаемость) в `~/.config/moodle-mcp/courses/`. Проверь сводную таблицу, которую он покажет,
и подтверди. После этого ответы про оценки и задания учитывают эти правила, включая политику
ИИ каждого курса: Claude помогает только так, как курс разрешает.

## Шаг 6. Попробовать

Спроси Claude:

- *«проверь мудл»* — покажет твоё имя, сайт и все ли функции доступны;
- *«что у меня по учёбе на неделе?»*;
- *«как подключиться к лабораторной VM из дома?»*;
- *«что нужно сделать в Homework R2?»*;
- *«как у меня с оценками?»*;
- *«сделай дашборд на две недели»*.

Ссылки в ответах открываются в браузере, где ты уже вошёл в Moodle.

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| `claude mcp get moodle` → *Failed to connect* | неверный путь к бинарнику или он не собран: выполни `make build` и проверь, что путь полный |
| «Токен Moodle недействителен или отозван» | получи новый токен (шаг 2) и подключи заново: `claude mcp remove moodle -s user`, затем шаг 3 |
| «не задан MOODLE_TOKEN» | в команде нет `-e MOODLE_TOKEN=…`, подключи заново |
| «функция не разрешена / access control» | токен от другого сервиса, нужен *Moodle mobile web service* |
| дедлайнов нет, хотя в Moodle они есть | преподаватели могут скрывать задания до открытия; в ответе будет «N скрыто» |
| данные устарели | попроси ещё раз «обнови» или «refresh»: курсы кэшируются на 15 мин, дедлайны на 5 |

Если всё равно не получается, спроси Claude *«мудл не работает, помоги»*. Скилл
**moodle-setup** пройдёт все проверки по шагам.

## Приватность

- Сервер работает на **твоём** компьютере и обращается только к `moodle.fh-joanneum.at`.
- То, о чём ты спрашиваешь (дедлайны, содержимое файлов, оценки), отправляется в Claude как
  часть разговора, как и всё, что ты вставляешь в чат. Не используй его для материалов, которые
  нельзя показывать ИИ-ассистенту.
- Скачанные файлы остаются на твоём компьютере в `MOODLE_DOWNLOAD_DIR`.
